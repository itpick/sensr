sensr

A firewall and router OS written in Rust, built on NixOS. It aims to match OPNsense feature for feature, with atomic upgrades and rollback.

In development: no images have been released yet. The buttons below go live with the first release. If you need a router today, use OPNsense for Raspberry Pi or VyOS for Raspberry Pi.

Related projects

  • vyos-pi: VyOS images for Raspberry Pi 4/5
  • OPNsense vs VyOS on the Pi 5: side-by-side speed and boot-time results

Benchmark: the performance evaluation measured OPNsense, VyOS and a NixOS + Rust prototype in x86 VMs. Over virtio with 8 TCP streams, Linux forwarded 25–26 Gbit/s and OPNsense 3.1. With 50 rules loaded, the prototype applied a one-rule change in 16 ms, OPNsense in 0.36 s and VyOS in 2.2 s. See also the startup comparison: the time until traffic flows, on an x86 VM and on a real Pi 5.

One-liner (Linux)

Writes the Pi 5 image straight to a disk. Replace /dev/sdX; everything on it is erased.

curl -fL https://github.com/itpick/sensr/releases/latest/download/sensr-pi5.img.zst | zstd -dc | sudo dd of=/dev/sdX bs=4M conv=fsync status=progress

Or, in Raspberry Pi Imager, choose Use custom and select the downloaded image.

First-boot settings

The FAT boot partition has a sensr/ folder, which works like the opnsense-pi/ folder in opnsense-pi:

FileEffect
config.jsonA full sensr config (a backup export), applied once and then renamed to config.json.applied.
seed.tomlA short hand-written seed: hostname, admin password hash or SSH keys, which NIC is LAN and WAN (by MAC), WAN type. Merged over the defaults, then renamed .applied.
config.xmlAn OPNsense backup, converted to sensr config on first boot. sensr/import-report.txt lists anything it couldn't map.
ifnames<mac> <name> lines that pin NIC names, so USB adapters can't swap LAN and WAN.
authorized_keysSSH keys for the admin account.
reboot-after-minutesA safety net for remote installs: reboots to the last good generation unless the new config is confirmed in time.

First boot

  1. Pi: update the EEPROM bootloader first (Raspberry Pi OS: sudo rpi-eeprom-update -a).
  2. Plug LAN into your computer. Without a seed, the first NIC found becomes LAN and the second becomes WAN; the console shows which is which.
  3. Open https://192.168.1.1 and finish the setup wizard. It makes you set an admin password.

Build it yourself

git clone https://github.com/itpick/sensr && cd sensr && nix build .#images.pi5
